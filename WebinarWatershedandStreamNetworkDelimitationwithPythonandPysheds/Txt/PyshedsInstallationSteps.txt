Go to:
https://www.lfd.uci.edu/~gohlke/pythonlibs/

And download the wheel packages for your python and computer configuration:
1. GDAL
2. Pyproj
3. Fiona
4. Shapely
5. Geopandas
6. Rasterio

Install the wheels with pip install:
pip install GDAL-2.4.1-cp37-cp37m-win_amd64.whl
pip install pyproj-2.1.3-cp37-cp37m-win_amd64.whl
pip install Fiona-1.8.6-cp37-cp37m-win_amd64.whl
pip install Shapely-1.6.4.post1-cp37-cp37m-win_amd64.whl
pip install geopandas-0.5.0-py2.py3-none-any.whl
pip install rasterio-1.0.22-cp37-cp37m-win_amd64.whl

And then install pysheds
pip install pysheds
